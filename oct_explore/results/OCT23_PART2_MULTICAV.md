# Oct 23 Exploration — Part 2: Multi-Cavity Scaling (`K = 4` Bits/Cavity, `n = 8, 12, 16, 20`)

## 0. Experimental Protocol & Audit Compliance
- **Encoding**: `K = 4` bits per cavity (`D = 2^4 = 16` computational Fock states `0..15`, `C = n / 4 in {2, 3, 4, 5}` cavities for `n in {8, 12, 16, 20}`, cutoff `N_Fock = 40`).
- **Strict Computational-Subspace SNAP**: All SNAP gates (both in `k_prep = 2, 3` state preparation and in all `L` circuit layers) act **exclusively on computational Fock states `0..15`**, with strictly `0` phase on leaked Fock levels `f >= 16`.
- **Leakage Accounted as Failure**: Any Fock population outside `0..15` in any cavity is excluded from `p_succ` and reported explicitly as `Leak%`.
- **No Classical Pre-Solving (`relabel = none`)**: Canonical variable ordering and polarity (`flips = 0`), with raw factor-graph degree features only (`fv[:, :, 3:7] = 0`). The vacuum `|0,0,...,0>` pre-solve rate is `1%` at `n = 8` and `0%` at `n = 12, 16, 20`.
- **Size-Transferable Training**: Shared parameters and GNN weights are trained **strictly on `n = 8, 12` training instances** (`TRB = 51e9`, selected on `n = 12` validation `VAB = 53e9`) and evaluated **zero-shot at `n = 16, 20`** on 100 unseen test instances per `n` (`TEB = 52e9`).

## 1A-ii. Ideal Cavity Gray Mixer `U_gray(β_{c,l})` + Per-Cavity `0..15` SNAP Phases + Factor-Graph GNN

> **Gray + `0..15` SNAP + GNN (`relabel = none`):** per cavity `c` and layer `l`, the GNN outputs `β_{c,l}` and **two** computational-subspace `0..15` diagonal SNAP gates (`Vp = exp(-i sout_{c,l}) · U_gray(β_{c,l}) · exp(-i θ_{c,l})`), plus optional per-clause cost weights `w_b` (`clause_w`). State prep uses the same `k_prep = 2` physical `0..15` `SNAP+D` blocks (`n=20` leak `1.44%`).
>
> **Finite-size ★T vs asymptotic B90 slope (verified by `@qumode_checker`):** `p2_gnn_gray_L15_mp64_cw` achieves ★T dual-beat vs WalkSATlm tries at every tested size `n = 8, 12, 16, 20` (**1.32/2.27, 1.90/4.10, 2.76/7.88, 3.95/12.18** vs **2.01/3.74, 2.92/6.28, 4.55/9.09, 5.63/14.2**), with median growth **1.0957ⁿ** matching WalkSATlm tries (**1.092ⁿ**). However, its B90 growth is **1.1530ⁿ** vs WalkSATlm tries B90 **1.116ⁿ** (and bare `p2_gray_L15` **1.1376ⁿ**): the GNN wins `n ≤ 20` via a ~36% lower B90 prefactor (`C_B90 = 0.72` vs `1.12`), not a flatter B90 exponent (extrapolating the fit crosses WalkSATlm tries B90 just above `n ≈ 24`).
