The bare Néel product state on contiguous cavities has symmetric weight 1/81. That is not the ground-state weight. The symmetric-subspace weight is not an upper bound on fidelity: Hc+FK is not symmetric inside a cavity, so the diagonal layer can leave that subspace. Random packings are not reflection-closed. Global parity is unchanged because every qubit is still in one cavity.

## Compile charge

G is the same 66 logical pairs as contiguous A. Intra-cavity pairs move from distances (1,1,2) to (2,2,4) on the sublattice map, still 12 intra and 54 inter bonds. Putting non-adjacent logical qubits into one cavity is a connectivity change relative to contiguous encoding. It is charged, not treated as free. Shell count and the three shared shell controls are unchanged. One diagonal profile is reused L times.
